# THE BOY WHO LOVED HER IN SILENCE

A free, mobile-friendly one-page landing site for the original romance manga.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your repository (not inside a subfolder).
2. Open repository **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site.

The Instagram button currently opens Instagram's homepage. Replace its URL in `index.html` with the exact manga account URL when confirmed.
